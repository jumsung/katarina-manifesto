# 원딜 카타리나 설명서

서포터와 함께 읽는 원딜 카타리나 가이드입니다.

## GitHub Pages에 반영하기
1. 저장소에서 기존 `index.html` 파일을 엽니다.
2. 연필 모양 Edit 버튼을 누르거나 새 `index.html`을 업로드하며 기존 파일을 덮어씁니다.
3. 이 패키지의 `index.html` 내용을 반영합니다.
4. Commit changes를 눌러 저장합니다.
5. GitHub Pages가 자동 갱신될 때까지 잠시 기다린 뒤 사이트를 새로고침합니다.

승률과 패치별 게임 내 세부 사항은 별도로 검증된 공식 통계가 아니라는 점을 페이지에 표시했습니다.
