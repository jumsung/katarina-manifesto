# 원딜 카타리나 선언문 사이트

이 폴더는 GitHub Pages로 공개할 수 있는 정적 웹사이트입니다.

## GitHub Pages로 공개하기
1. GitHub에 로그인하고 새 repository를 만듭니다. 예: `katarina-manifesto`
2. Repository는 **Public**으로 설정합니다.
3. `Add file` → `Upload files`를 눌러 `index.html`을 업로드하고 커밋합니다.
4. Repository의 `Settings` → `Pages`로 이동합니다.
5. `Build and deployment`에서 `Deploy from a branch`를 선택합니다.
6. Branch를 `main`, folder를 `/(root)`로 설정하고 `Save`를 누릅니다.
7. 잠시 기다리면 Pages 화면에 공개 URL이 표시됩니다.

## 문구 수정
`index.html` 파일을 편집하면 됩니다. 사이트의 본문 문구는 HTML 안에 있고, 색상과 디자인은 `<style>` 영역에서 조정할 수 있습니다.

## 참고
- 이 페이지는 비공식 팬 페이지입니다.
- 공식 LoL 아트워크를 포함하지 않고 CSS 디자인으로 구성했습니다.
